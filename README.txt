SOM SHARMA - PERSONAL PORTFOLIO
"I am a Failure!!!!"
================================

A single-page personal portfolio made with plain HTML and CSS.
No JavaScript and no frameworks are used.


HOW TO RUN
----------
1. Unzip the folder.
2. Open the folder "som-sharma-portfolio".
3. Double-click index.html. It opens in your web browser.

An internet connection is only needed to load the two Google Fonts
(Caveat and Lora). Without internet the page still works and uses
fonts already on the computer instead.


FOLDER STRUCTURE
----------------
som-sharma-portfolio/
  index.html                   - the main page
  sapne.html                   - reading page for my piece "Sapne"
  style.css                    - all colours, fonts and layout (used by both pages)
  images/                      - all photographs
  README.txt                   - this file


IMAGES (REPLACE BEFORE SUBMITTING)
----------------------------------
The files in the images folder are placeholders. Replace each one
with a real photograph and keep the same file name, so the HTML
does not need to change.

  portrait.jpg  - my own portrait (tall photo, around 900 x 1100)
  laptop.jpg    - stock photo: laptop and notebook on a desk
  cinema.jpg    - stock photo: cinema, camera or film set
  writing.jpg   - stock photo: notebook and pen, or a typewriter
  road.jpg      - stock photo: open road, sunset or horizon (wide photo)

Free stock photos: https://unsplash.com and https://www.pexels.com
Landscape photos about 1600 pixels wide work well.

HOW TO ADD A NEW WRITING PIECE
------------------------------
1. Make a copy of sapne.html and rename it, for example mypiece.html.
2. Open it and replace the title and the paragraphs with the new piece.
3. In index.html, find the block that starts with <div class="piece">,
   copy it, paste it below, and change the title, the excerpt and the
   link (href="mypiece.html").


DESIGN IDEA
-----------
The page is made to look like my notebook:
- handwriting font for headings
- red pen for marks, circles, crossed-out words and notes
- yellow highlighter for the important lines
- photos shown like prints stuck on the page, slightly tilted

Colours (all set once at the top of style.css):
